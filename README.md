<H1>Task Manager</H1>

<h2>Descripció</H2>
Aplicació per gestionar tasques personals des de la línia de comandes.

<h2>Funcionalitats</H2>
<ul>
<li>Crear tasques</li>
<li>Llistar tasques</li>
<li>Eliminar tasques</li>
<li>Marcar tasques com a completades</li>
</ul>

<h2>Instal·lació</H2>
Ha de mostrar un bloc de codi amb:
<pre><code>git clone https://github.com/Marco011101/taskmanager.git</code></pre>

<h2>Ús</H2>
Ha de mostrar un bloc de codi amb:
<pre><code>node app.js</code></pre>
